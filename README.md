# 🚀 Portfolio Moderne - Abdoulaye Yalcouyé

Ce projet est un portfolio interactif et responsive conçu pour un développeur Frontend/Backend (CROSS-PLATFORM). L'interface utilise un design "Dark Mode" élégant avec des effets de flou (Glassmorphism), des animations fluides et une navigation par sections (Single Page Application logic).

## 📸 Aperçu des Sections
* **Accueil (Hero) :** Présentation principale avec photo de profil et liens sociaux.
* **À propos (About) :** Description détaillée du profil professionnel.
* **Résumé (Resume) :** Section dynamique avec trois onglets interchangeables :
    * **Experience :** Parcours professionnel.
    * **Skills :** Grille d'icônes technologiques (HTML5, CSS3, JS, React, etc.).
    * **Education :** Liste des diplômes et formations sous forme de cartes.

## ✨ Fonctionnalités clés
-   **Navigation Fluide :** Changement de sections sans rechargement de page via JavaScript.
-   **Système d'Onglets Dynamique :** Dans la section Resume, passez de l'expérience aux compétences ou à l'éducation avec une animation de fondu (`fade-in`).
-   **Design Responsive :** Adapté aux ordinateurs, tablettes et mobiles grâce à CSS Flexbox et Grid.
-   **Tooltips Interactifs :** Bulles d'aide personnalisées sur la navigation flottante et les icônes sociales.

## 🛠️ Technologies utilisées
* **HTML5** : Structure sémantique.
* **CSS3** : Variables CSS, Flexbox, Grid, Animations personnalisées.
* **JavaScript (Vanilla)** : Logique de switch de pages et gestion des onglets.
* **Font Awesome** : Bibliothèque d'icônes.
* **Google Fonts** : Police "Inter" pour une typographie moderne.
